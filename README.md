# Face Mask Detection

A deep learning project to detect whether people are wearing face masks properly in images and video streams.  
Built using **YOLOv8** for object detection with three classes:  
- ✅ Mask  
- ❌ No Mask  
- ⚠️ Improper Mask  


## Features
- Real-time detection on images, videos, and webcam  
- Lightweight and fast (runs on CPU or GPU)  
- Easy to train on custom datasets
